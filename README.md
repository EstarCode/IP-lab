# Personal Profile Website

> **Internet Programming I (SWEG3107)**  
> Department of Software Engineering, Addis Ababa Science and Technology University (AASTU)

A multi-page personal portfolio website built with pure semantic HTML5 demonstrating modern markup, media embedding, navigation hierarchy, tables, accessible forms, and rich content structure.

---

## Website Structure

The website consists of six core pages interconnected through a consistent navigation header:

1. **Home (`index.html`)**
   - Welcome introduction and profile hero section.
   - Global navigation menu.
   - Summary previews linking to each main section.
   - Semantic `<header>`, `<main>`, `<section>`, and `<footer>` elements.

2. **About Me (`about.html`)**
   - Personal biography and background.
   - Educational overview table with institution details.
   - Personal interests, quotes, and abbreviations (`<abbr>`).

3. **Skills and Education (`skills.html`)**
   - Detailed educational background table with row/column spans.
   - Technical and professional skills matrix.
   - Visual progress tracking with HTML5 `<progress>` and `<meter>` elements.
   - Interactive disclosure widgets using `<details>` and `<summary>`.

4. **Projects & Achievements (`projects.html`)**
   - Portfolio showcase featuring EthioFarm and Finkison AI.
   - Figure elements with captions (`<figure>`, `<figcaption>`).
   - Categorized nested lists outlining system architecture.
   - Direct download link for project documentation (`files/project-report.pdf`).

5. **My Media and Interests (`media.html`)**
   - Native HTML5 `<audio>` player with fallback formats (`.mp3`, `.wav`).
   - Native HTML5 `<video>` player with poster image and timed subtitles (`captions.vtt`).
   - Responsive embedded YouTube media using `<iframe>`.
   - External curated learning resources.

6. **Contact Me (`contact.html`)**
   - Direct email contact link.
   - Comprehensive HTML5 form with grouped fieldsets (`<fieldset>`, `<legend>`).
   - Diverse input controls: `text`, `email`, `number`, `date`, `color`, `range`, `radio`, `checkbox`, `select`, and `textarea`.
   - Built-in client-side validation attributes (`required`, `min`, `max`, `placeholder`).
